Cleanup pass across the repo, five independent items.

1. lib/db/drizzle.config.ts uses
     schema: path.join(__dirname, "./src/schema/index.ts")
   __dirname is undefined under ESM (lib/db/package.json sets
   "type": "module"), and on Windows the backslashes it produces are read as
   escapes by drizzle-kit's glob, so `pnpm --filter @workspace/db run push`
   fails outside Replit. Change it to the config-relative literal
   "./src/schema/index.ts" and drop the now-unused path import. The package
   script always runs with cwd = lib/db so this is equivalent.

2. The root package.json has TWO "dev" keys. The second silently wins,
   making the first dead. Remove the dead one and keep the behaviour that is
   actually in use (node ./scripts/dev.mjs).

3. artifacts/api-server/src/lib/corporate-actions.ts is 655 lines of dead v1
   domain logic: nothing imports it. It has a different status vocabulary, a
   different required-term key set, its own seeder, and a different spelling
   of the simulated-instruction label. Delete it. Before deleting, check
   nothing you want has been left behind in it.

4. artifacts/api-server has TWO test directories. tests/ (plural) holds five
   legacy unit tests that are outside the test/*.test.ts glob that pnpm test
   uses, so they never run, and one of them asserts a reconciliation error
   message that no longer exists so it would fail if run. Committed stale
   compiled output sits in .test-dist/. Migrate the four still-valid tests
   into test/, delete the stale one, delete tests/ and .test-dist/, and add
   .test-dist/ and dist/ to .gitignore.

5. artifacts/api-server/src/app.ts has no error-handling middleware and no
   404 handler, so any unguarded throw returns Express's default HTML 500
   with a stack trace outside production. Add a JSON error handler that logs
   the real error server-side and returns a safe JSON body, plus a JSON 404
   for unmatched /api routes. Do not change the existing per-route 400 / 404
   / 409 handling.

Verify after each item: pnpm run build and pnpm test both pass.
