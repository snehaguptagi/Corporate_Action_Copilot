---
name: Rights decision controls
description: Decision and submission rules for voluntary rights issues.
---

Rights decisions must compare exercise, sell entitlement, and lapse at scheme level. Exercise quantities default to the full entitlement or the strictest permitted maximum. Any constrained remainder defaults to sale, never lapse, while the server rejects exercise quantities above cash or concentration limits. The Fund Manager submits one complete package to Compliance.

**Why:** Per-scheme submit buttons and unquantified warning labels allowed decisions that contradicted the stated controls.

**How to apply:** Let a scheme split between exercise and sale, keep lapse explicit, show live cash, sale, and forfeiture consequences, set browser input maxima to server maxima, and preserve maker-checker separation.
